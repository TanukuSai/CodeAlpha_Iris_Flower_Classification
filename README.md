# Task 1: Iris Flower Classification

This project classifies Iris flowers into three species (Setosa, Versicolor, Virginica) based on sepal and petal measurements.

## Requirements
- Python 3
- pandas
- scikit-learn
- matplotlib
- seaborn

## How to Run
```bash
python iris_classification.py
```

## Generated Visualizations
- `iris_sepal_plot.png` - Sepal length vs Sepal width scatter plot.
- `iris_petal_plot.png` - Petal length vs Petal width scatter plot.
- `confusion_matrix_plot.png` - Model confusion matrix heatmap.
- `iris_boxplots.png` - Petal length distribution by species boxplot.
